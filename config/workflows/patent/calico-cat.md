## 专利工作流（三花猫：模型抽象合理性与整体自洽评审）

### 评审规程
- 评审总原则：围绕“模型边界是否清楚、层次是否合理、整体是否自洽”展开，不去扣细枝末节。先思考怎样的概念分层、因果链和匹配链路最合理，再审查当前文本是否按这个合理结构完整表达。
- **重点关注如下**：
  - 感知通道模型是否抽象合理，通道划分是否正交、完备，通道之间是否存在语义重叠或遗漏
  - 通道属性模型是否合理，字段归属是否清楚，每个字段的来源、用途、约束和与其他模型的关系是否解释完整
  - 感知内容单元模型整体是否合理，是否能作为通道内容、内容类型和策略匹配之间的稳定中间层，各字段来龙去脉是否闭合
  - 感知内容类型分类模型是否正交、完备，分类层级是否与通道模型、内容单元模型发生混杂
  - 各通道内容详细结构化规范是否与通道属性、内容单元、内容类型保持一致，是否存在同一概念多处定义
  - 通道层策略模型的职责边界是否清楚，逐字段说明其如何参与匹配、如何生效、与内容层和语义层策略如何衔接
  - 内容层策略模型的职责边界是否清楚，逐字段说明其如何参与匹配、如何生效、与通道层和语义层策略如何衔接
  - 语义层策略模型的职责边界是否清楚，逐字段说明其如何参与匹配、如何生效、与通道层和内容层策略如何衔接
  - 三层策略的匹配顺序、冲突处理和生效关系是否闭合，是否形成可追踪的“输入-匹配-决策-执行”链路
  - 网络侧感知控制模型与前述模型之间的输入输出关系是否闭合；例如资源访问管控逻辑上需要资源 id，但资源 id 的获得方式可以是网络侧识别或端侧报文携带，不应把逻辑依赖和实现路径混为一谈
  - 字段归属是否合理，是否存在重复建模、语义重叠或上下位混杂
  - 某些字段是否放错层、重复出现，或与已有字段形成冲突
- 输出时优先抓关键矛盾点：直接指出最影响整体结构自洽的问题，不要把注意力耗在次要枝节上。
- 每轮反馈尽量回答清楚：核心不自洽点 / 边界最模糊的位置 / 重复建模点 / 需要补强的约束或推导。

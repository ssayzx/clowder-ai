## 专利工作流（三花猫：模型抽象合理性与整体自洽评审）

### 评审规程
- 评审总原则：围绕“模型边界是否清楚、层次是否合理、整体是否自洽”展开，不去扣细枝末节。
- 重点关注：
  - 通道模型、通道属性模型、感知内容单元模型、内容类型分类模型之间的边界是否清楚
  - 字段归属是否合理，是否存在重复建模、语义重叠或上下位混杂
  - L-CH / L-CT / L-SM 三层策略的职责边界、匹配顺序和生效关系是否闭合
  - 某些字段是否放错层、重复出现，或与已有字段形成冲突
  - 网络侧感知控制模型与前述模型之间的输入输出关系是否闭合
- 输出时优先抓关键矛盾点：直接指出最影响整体结构自洽的问题，不要把注意力耗在次要枝节上。
- 每轮反馈尽量回答清楚：核心不自洽点 / 边界最模糊的位置 / 重复建模点 / 需要补强的约束或推导。
